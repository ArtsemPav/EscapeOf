## Обзор

Загадка «Пятнашки» (скользящий пазл). Игрок щёлкает по плиткам — каждая перемещается на соседнюю пустую клетку. Цель — собрать изображение (нарезанное из атласа) или порядок номеров. После победы взаимодействие блокируется, результат сохраняется. Готовая конфигурация — 3×3, но сетка поддерживает любые размеры.

## Компоненты

### `FifteenPuzzleManager`

Файл: `Assets/Scripts/Puzzle/FifteenPuzze/FifteenPuzzleManager.cs`. Логика сетки: генерация, перемешивание, проверка победы. Реализует `ISaveable`. Пространство имён `PuzzleGame`.

**Save**

| Поле      | Описание                                                                      | Default             |
| --------- | ------------------------------------------------------------------------------ | --------------------- |
| `Save ID` | Уникальный ID для системы сохранений (default: `"fifteen_puzzle"`) | `"fifteen_puzzle"`    |

**Events**

| Поле              | Описание                                        |
| ----------------- | ------------------------------------------------- |
| `On Puzzle Solved`| UnityEvent, срабатывает один раз при решении      |

**Grid Settings**

| Поле      | Тип    | Описание                                            | Default |
| --------- | ------ | ------------------------------------------------------- | ------- |
| `Width`   | int    | Ширина сетки (в плитках)                                 | `3`     |
| `Height`  | int    | Высота сетки (в плитках)                                 | `3`     |
| `Spacing` | float  | Расстояние между центрами плиток, локальные единицы      | `0.22`  |

**Setup**

| Поле       | Тип                           | Описание                                                                        |
| ---------- | ------------------------------- | --------------------------------------------------------------------------------- |
| `Elements` | List&lt;FifteenPuzzleElement&gt; | Плитки пазла. Если пусто — автоматически собираются из дочерних объектов (в порядке иерархии) |

**Audio**

| Поле               | Тип       | Описание                        | Default |
| ------------------ | --------- | --------------------------------- | ------- |
| `Move Sound`       | AudioClip | Звук хода плитки                  | —       |
| `Move Sound Volume`| float     | Громкость звука хода (0–1)        | `0.7`   |

**Visual Settings**

| Поле             | Тип     | Описание                                                                                       | Default |
| ---------------- | ------- | -------------------------------------------------------------------------------------------------- | ------- |
| `Use Image Atlas`| bool    | Нарезать изображение по плиткам из материала с текстурой-атласом                                    | `true`  |
| `Puzzle Material`| Material| Материал с текстурой-атласом. Каждой плитке создаётся экземпляр с индивидуальными tiling/offset    | —       |

### `FifteenPuzzleElement`

Файл: `Assets/Scripts/Puzzle/FifteenPuzze/FifteenPuzzleElement.cs`. Одна плитка. Требует `BoxCollider`. Реализует `IInteractable` — ход выполняется ЛКМ по плитке (курсор-рука, текст «Move Tile», неперемещаемый предмет).

**Movement Settings**

| Поле        | Тип    | Описание                                        | Default |
| ----------- | ------ | --------------------------------------------------- | ------- |
| `Move Speed`| float  | Скорость плавного перемещения (Lerp за deltaTime)   | `10`    |

**Debug Settings**

| Поле             | Тип               | Описание                                                                       | Default |
| ---------------- | ------------------- | ---------------------------------------------------------------------------------- | ------- |
| `Number Text`    | TextMeshPro         | Опциональный номер плитки (targetIndex + 1)                                        | —       |
| `Show Debug Text`| bool                | Показывать ли номер (активирует/деактивирует объект Number Text)                   | `false` |

Поля `GridPosition` (текущая клетка) и `TargetIndex` (индекс в собранном состоянии) назначаются менеджером через `Initialize()`.

## Логика работы

```
Старт (FifteenPuzzleManager.Start)
  → InitializeGrid(): плитки раскладываются по сетке слева направо, сверху вниз
      → последняя клетка (правый нижний угол) остаётся пустой (emptyPosition)
  → Use Image Atlas + материал → ApplyAtlasToElements():
      каждой плитке — экземпляр материала с tiling = (1/W, 1/H)
      и offset по её TargetIndex (ось Y инвертирована: UV-начало снизу)
  → Загружено из сейва как решённое?
      → RestoreSolvedState(): плитки расставляются по TargetIndex,
        коллайдеры выключаются, OnPuzzleSolved вызывается молча
      → Иначе: DelayedShuffle() — пауза 1 сек, затем Shuffle(W×H×10) случайных
        ходов мгновенными свопами (гарантированно решаемая позиция)

Ход игрока
  → ЛКМ по плитке → Interact() → manager.TryMoveElement(this)
      → блокировки: isShuffling / isPuzzleSolved
      → клетка соседняя с emptyPosition? (по вертикали/горизонтали)
          → MoveElementToEmpty(): своп в логической сетке,
            звук Move Sound, плавное перемещение MoveTo() (корутина)
          → CheckWinCondition()

CheckWinCondition()
  → обход сетки по индексам: у каждой плитки TargetIndex == порядковый индекс,
    пустая клетка — строго последняя
  → Совпало → HandlePuzzleSolved()

HandlePuzzleSolved()
  → isPuzzleSolved = true, ProgressLogger.Log("puzzle_solved", _saveId)
  → коллайдеры всех плиток выключаются (взаимодействие блокируется)
  → SaveManager.Save()
  → OnPuzzleSolved.Invoke() → связанные системы (PuzzleSolvedCinematic и т.п.)
```

## Быстрая настройка в сцене

1. Создайте корень пазла и добавьте `FifteenPuzzleManager` (или используйте `Assets/Prefabs/puzzle/FifteenPuzzle/PRF_FifteenPuzzle.prefab`).
2. Создайте дочерние объекты-плитки с `BoxCollider` и `FifteenPuzzleElement` (+ меш с материалом). Количество плиток = Width × Height − 1.
3. Назначьте плитки в список **Elements** (или оставьте пустым — соберутся из детей в порядке иерархии).
4. Настройте **Width** / **Height** / **Spacing** под размер мешей.
5. Назначьте **Puzzle Material** с текстурой-атласом и оставьте **Use Image Atlas** включённым — нарезка выполнится автоматически.
6. (Опционально) Назначьте **Move Sound**.
7. Подключите **On Puzzle Solved** к следующему шагу пазла (камера, дверь, звук и т.п.).
8. Установите уникальный **Save ID**.
9. Отметьте плитки слоем, кликабельным в режиме загадки (как у остальных `IInteractable`-объектов).

## Важные детали

- Перемешивание — случайными **легальными ходами** от собранного состояния, поэтому пазл всегда решаем.
- Победа требует строгого совпадения всех `TargetIndex`, пустая клетка — только последняя (правый нижний угол).
- Плитка «двигается» плавной корутиной `MoveRoutine`; при повторном вызове `MoveTo` предыдущая корутина останавливается.
- Сохраняется только факт решения (`isSolved`); промежуточная расстановка плиток не персистентна — при незавершённой игре сетка заново перемешивается.
- В решённом состоянии плитки восстанавливаются по `TargetIndex` с выключенными коллайдерами — повторный `OnPuzzleSolved` вызывается молча, чтобы связанные системы восстановили визуал.
- Для отладки можно включить номера плиток (`Show Debug Text`) — объект `Number Text` должен быть назначен.
- Публичный метод `AutoSolve()` мгновенно расставляет плитки по целевым позициям — используется редакторным читом `Assets/Scripts/Editor/PuzzleCheats/FifteenPuzzleUnlockTool.cs`.
