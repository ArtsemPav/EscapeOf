Заставка пробуждения в комнате 7 — первая кат-сцена игры: игрок просыпается на кровати, оглядывает комнату и встаёт, получая управление с взгляда на записке. Работает только на **новой игре** — при загрузке сейва пропускается целиком.

> Как делать такие заставки и почему камера в них ведёт себя именно так — см. скилл **unity-fps-cinematic-intro** (`/.bezi/skills/unity-fps-cinematic-intro/SKILL.md`) и страницу [@ id="/Pages/Private/Endings and Credits Architecture.md" label="Endings and Credits Architecture"] — вторая кинематика проекта.

---

## Архитектура

```
Room 7/Props/bed_B
├── LyingPoint          # голова лежащего игрока; forward = ноги→голова
├── SitPoint            # высота сидячей головы (~1.95) + край кровати
└── StandPoint          # где стоит капсула всю заставку и куда встаёт игрок

Room 7/IntroGazePoints
├── Point_Door          # цель взгляда лёжа (после лампы)
└── Point_Locker        # цель взгляда стоя (шкаф)

Room 7/WakeUpIntro      # WakeUpIntroController + временный Volume заставки
```

Скрипты:

- `WakeUpIntroController.cs` — `/Assets/Scripts/Core/` — вся последовательность
- `EyelidOverlay.cs` — `/Assets/Scripts/Effects/` — полноэкранные веки (Canvas + блинки)

Ключевой контракт: **камера проигрывает тело в мировых координатах** (`TakeCameraWorldOverride`), капсула всё время стоит на `StandPoint` (гравитация и триггеры комнат работают). Риг отдаёт камеру через `SetCinematicControl(true)` + `TakeCameraWorldOverride()` и забирает `ReturnCameraWorldToRig()`.

## Фазы (текущая версия)

```
1. Setup      — экран чёрный: капсула телепортируется в StandPoint,
                камера в LyingPoint (мировая поза закреплена пином)
2. Wake       — веки: полуоткрытие → 2 моргания по Focus Ladder,
                размытие уходит СТУПЕНЧАТО, каждый шаг спрятан под веком
3. Лампа      — взгляд отдыхает на каждом уровне лестницы; финальный
                уровень (0) — чёткая лампа перед поворотом
4. Дверь      — лёжа ПЕРВЫЙ gaze-ближний бой: дверь обрабатывается тем же
                LyingGazeBeatRoutine, что записка и стол. Дефокус доезжает
                до 0.95 уже к 30% поворота (дверь входит в кадр УЖЕ размытой)
                и не разрешается весь бит — маскировка мэда у двери;
                размытие разрешает следующий бит (записка)
5. Записка+стол — лёжа саккады по Lying Extra Gaze Targets
                (записка, стол): поворот DrowsyEase + покачивание головы,
                случайное удержание 1.2–2.2 с; унаследованный с двери блур
                0.95 разрешается на записке. В момент ПРИБЫТИЯ взгляда на
                записку (под блюром) Scare Maid выключается — vanish-while-looking;
                у стола фокус уже полный и мэйда нет
6. Встать     — ОДНО непрерывное движение из лёжачей позы: дуга Безье
                через ноги, наклон вперёд, взгляд вниз на постановку ног,
                подъём к Stand Gaze Target (стол); вес Volume → 0
7. Записка    — медленный сонный доворот тела+камеры к FtueBook,
                удержание, возврат управления
```

- ESC в любой момент — скип (fast-forward к передаче управления).
- Запуск: `WakeUpIntroController.RequestStart()` из главного меню → флаг через `SaveManager.RequestWakeUpIntro()` → `Start()` в новой сцене.

## Постобработка

Временный `Volume` на объекте `WakeUpIntro` (приоритет выше игровых), профиль строится в рантайме:

- `DepthOfField` (Gaussian) — «несфокусировавшийся» взгляд; дисторсия даёт ложный зум и не используется
- `ColorAdjustments` — десатурация −55, экспозиция −0.7 (сон)
- Управление настроением — через **вес Volume**, ступенчато по `Focus Ladder` (по умолчанию 1 → 0.6 → 0): каждый блинк прячет один шаг
- Лестница настраивается в инспекторе; предфинальные уровни держать ~0.5+ — низкий вес DoF визуально не отличим от резкости и «съедает» блинк
- Скрытый в моргании шаг — ключевая техника: скачок веса происходит под закрытыми веками и не виден
- По завершении/скипе: `weight = 0`, `enabled = false` — игровые Volume возвращаются нетронутыми

## Ключевые поля WakeUpIntroController

### Bed (Room 7)


| Поле                         | Описание                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| **Lying Point**              | голова лежащего; forward = направление «ноги → голова»                                       |
| **Stand Point**              | где капсула стоит всю заставку; куда игрок встаёт                                            |
| **Bed Gaze Target**          | записка (FtueBook) — финальный взгляд                                                        |
| **Lying Gaze Target**        | лампа — первый взгляд при открытии глаз                                                      |
| **Lying Second Gaze Target** | дверь — второй взгляд лёжа                                                                   |
| **Stand Gaze Target**        | стол — куда приходит взгляд В КОНЦЕ подъёма                                                  |
| **Lying Extra Gaze Targets** | доп. взгляды лёжа после двери (записка, стол) — по порядку                                   |
| **Scare Maid**               | проп-скейр (MaidHolder): включается на старте, исчезает в момент прибытия взгляда на записку |


### Timing / Choreography


| Поле                     | Значение | Описание                                         |
| ------------------------ | -------- | ------------------------------------------------ |
| First Part Open Duration | 2.2      | полуоткрытие глаз                                |
| Final Open Duration      | 3.5      | полное открытие                                  |
| (дверь = первый beat)    | —        | длительность по углу 2.4–4.2 с + Hold Range      |
| (Door Rest удалено)      | —        | удержание двери теперь из Hold Range (1.2–2.2 с) |
| Lying Gaze Hold Range    | 1.2–2.2  | случайное удержание на каждой лёжачей цели       |
| Stand Up Duration        | 2.0      | непрерывный подъём (взгляд → стол)               |
| Focus Ladder             | 0.6/0    | вес Volume после каждого моргания; последний = 0 |
| Lamp Focus / Sharp Hold  | 2 / 2    | удержание мягкого уровня и чёткой лампы          |
| Wander Defocus Weight    | 0.45     | всплеск размытия во время лёжачих поворотов      |
| Head Sway Degrees        | 0.7      | амплитуда покачивания головы в удержании         |
| Slow Turn Duration       | 1.4      | финальный поворот к записке                      |
| Gaze Hold Time           | 1.1      | удержание взгляда на записке                     |


Профиль всех поворотов — `DrowsyEase` (квинтический smootherstep на `p^0.75`):
один мягкий импульс — плавный разгон, скромный пик (~1.8× средней) на трети
пути и длинный монотонный хвост до нуля у цели. Никаких overshoot-ов и бамперов:
любой дополнительный член в зоне торможения читается как рывок.

### Audio

- **Wake Sound** — вдох при полуоткрытии глаз (`WakeSound` на объекте заставки, клип `startSequence.aif` — длинный саунд, подогнанный под всю секвенцию; играет один раз при полуоткрытии)
- **Ambient Source** — эмбиент комнаты, fade-in за время заставки

## Решённые проблемы (не повторять)


| Было                             | Причина                                                 | Решение                                                                    |
| -------------------------------- | ------------------------------------------------------- | -------------------------------------------------------------------------- |
| Камера под матрасом              | капсула оседает под гравитацией, head bob тащит камеру  | пин мировой позиции камеры (`PinCameraRoutine`) до начала фаз              |
| Вид сквозь потолок в небо        | телепорт в триггер комнаты не вызывает `OnTriggerEnter` | `RoomVisibilityManager.ReconcileAfterSpawn()`                              |
| Взгляд нырял в пол при поворотах | pitch из полной ротации заворачивался                   | явный yaw/pitch через `Atan2` + `DeltaAngle`, кламп ±45°                   |
| Зум на лампе                     | дисторсия читалась как приближение                      | дисторсия убрана, эффект «фокуса» = остаточный DoF-блур                    |
| Двойной подъём / лишняя дуга     | `RiseRoutine` запускался повторно                       | один вызов подъёма; подъём целился сразу в финальную цель                  |
| Ускорение + резкая остановка     | overshoot-бампер в зоне торможения поворота             | бампер убран; один скошенный профиль `DrowsyEase`                          |
| Два рывка в одном повороте       | бампер в середине делил движение на два импульса        | один член кривой, никаких наложений                                        |
| Рывок в начале поворота          | полный smootherstep, сжатый в первые 30% (пик ~3.5×)    | `DrowsyEase`: разгон на всю первую треть, пик ~1.8×                        |
| Снап при передаче управления     | несовпадение скриптовой позы и риг-позы                 | телепорт тела под камеру + `SetCinematicControl(false→true)` ре-синк питча |
