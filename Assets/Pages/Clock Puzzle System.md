## Обзор

Загадка «Часы». Игрок входит в режим загадки, перетаскивает мышью часовую и минутную стрелки (дискретное вращение с щелчками) и выставляет заданное время. Контроллер проверяет положение обеих стрелок при каждом отпускании кнопки и помечает загадку решённой. Система также управляет тиканьем, маятником (синхронизированным с аудио-волновой формой) и может сдвигать часы после решения (например, чтобы открыть тайник).

## Компоненты

### `ClockPuzzleController`

Файл: `Assets/Scripts/Puzzle/Clock/ClockPuzzleController.cs`. Главный контроллер загадки. Размещается на корневом объекте часов ([RequireComponent] `PuzzleModeController`). Находит стрелки, маятник и проверяет решение.

**Correct Time**

| Поле               | Тип    | Описание                                        | Default |
| ------------------ | ------ | ----------------------------------------------- | ------- |
| `Target Hour`      | int    | Целевой час (0–11, 12-часовой формат)           | `6`     |
| `Target Minute`    | int    | Целевая минута (0–59)                           | `0`     |
| `Tolerance Minutes`| int    | Допустимое отклонение в минутах (0 = точное)    | `0`     |

**Randomization**

| Поле                    | Тип | Описание                                                                | Default |
| ----------------------- | --- | ----------------------------------------------------------------------- | ------- |
| `Minute Hand Min Distance` | int | Минимальный стартовый отступ минутной стрелки от решения (из 60)     | `15`    |
| `Hour Hand Min Distance`   | int | Минимальный стартовый отступ часовой стрелки от решения (из 12)      | `3`     |

**Solve Behavior**

| Поле            | Тип                  | Описание                                                                                     | Default        |
| --------------- | -------------------- | ---------------------------------------------------------------------------------------------- | -------------- |
| `Solve Behavior`| `ClockSolveBehavior` | `StopOnSolve` — тикает с начала и останавливается при решении; `StartOnSolve` — молчит до решения | `StopOnSolve`  |

**Tick (looping)**

| Поле               | Тип       | Описание                                                         | Default |
| ------------------ | --------- | ---------------------------------------------------------------- | ------- |

**Peak Detection**

| Поле               | Тип    | Описание                                                       | Default |

**Solved Chime**

**On Solve: Movement**

| Поле               | Тип             | Описание                                                 | Default        |

### `ClockHand`

Файл: `Assets/Scripts/Puzzle/Clock/ClockHand.cs`. Перетаскиваемая стрелка. Требует `Collider` на объекте и `PuzzleModeController` в родителях. Реализует `ISaveable` — Save ID фиксируется по типу стрелки (`clock_minute_hand` / `clock_hour_hand`), ручная настройка не нужна.

**Hand Settings**

| Поле       | Тип              | Описание                                  | Default   |
| ---------- | ---------------- | ------------------------------------------- | --------- |
| `Hand Type`| `ClockHandType`  | `Minute` (60 шагов по 6°) или `Hour` (12 шагов по 30°) | `Minute` |

**Rotation**

| Поле                         | Тип     | Описание                                                    | Default    |
| ---------------------------- | ------- | ------------------------------------------------------------- | ---------- |
| `Rotation Axis`              | Vector3 | Локальная ось вращения                                        | `(0,0,1)`  |

| `Rotation Speed`             | float   | Скорость плавного доворота, °/сек                              | `360`      |
| `Max Input Rotation Speed`   | float   | Максимальная скорость вращения от ввода, °/сек                | `540`      |

**Rotation Constraint**

| Поле                         | Тип  | Описание                                                                                     | Default |
| ---------------------------- | ---- | ------------------------------------------------------------------------------------------------- | ------- |

### `PendulumSwing`

Файл: `Assets/Scripts/Puzzle/Clock/PendulumSwing.cs`. Синусоидальное колебание маятника вокруг настраиваемой оси. Начальная локальная ротация — нижняя точка дуги. При заданных tick-данных фаза выводится из таймстампов аудио-пиков (один интервал = полупериод между двумя пиками); без данных — фолбэк на системное время. Старт/стоп управляются контроллером через `StartSwing()` / `StopSwing()`.

| Поле                | Тип     | Описание                                              | Default   |
| ------------------- | ------- | ------------------------------------------------------- | --------- |
| `Amplitude`         | float   | Максимальный угол качания в каждую сторону, °            | `15`      |
| `Fallback Frequency`| float   | Колебаний в секунду без аудио-синхронизации              | `1`       |
| `Swing Axis`        | Vector3 | Локальная ось качания                                   | `(0,0,1)` |
| `Settle Speed`      | float   | Скорость возврата в нижнюю точку после остановки, °/сек  | `90`      |

### Перечисления

- `ClockHandType` (`ClockHandType.cs`) — `Minute`, `Hour`.
- `ClockSolveBehavior` (`ClockSolveBehavior.cs`) — `StopOnSolve`, `StartOnSolve`.
- `ClockMoveAxis` (`ClockMoveAxis.cs`) — `X`, `Y`, `Z`, `Custom`.

## Логика работы

```
Старт (ClockPuzzleController.Start)
  → Стрелки уже восстановлены из сейва? → пропустить рандомизацию
  → Иначе: RandomizePosition() обеих стрелок
      (случайный шаг не ближе _minuteHandMinDistance / _hourHandMinDistance к решению)
  → StopOnSolve: StartTick() — зацикленный 3D-тик через AudioManager
      + AnalyzePeaks(): анализ волновой формы клипа, детект пиков
      + PendulumSwing.SetTickData(source, peaks, clipLength)
  → StartOnSolve: маятник остановлен, часы молчат

Игрок в режиме загадки тянется к стрелке (ClockHand.Update)
  → Рейкаст курсора: ввод реагирует только на стрелку под курсором
  → Захват ЛКМ → HandleDrag(): угол мыши вокруг центра стрелки на экране
  → Аккумулятор угла: каждые _stepAngle (6° / 30°) — RotateDiscrete(±1)
      → щелчок Tick Sound + OnStepChanged
  → _clockwiseOnly: движение против часовой игнорируется
  → Применение плавной ротации к целевому шагу (RotateTowards)

Игрок отпускает ЛКМ
  → OnReleased → ClockPuzzleController.CheckSolution()
      → минутная и часовая (час×5) сравниваются с целью на круговой шкале
        с допуском _toleranceMinutes
  → Совпало → PuzzleModeController.SetSolved()

HandleSolved()
  → Chime через AudioManager.Play3DOneShot
  → StopOnSolve: StopTick() (источник уничтожается) + маятник плавно останавливается
  → StartOnSolve: StartTick() + маятник начинает качаться
  → MoveOnSolve: корутина MoveCoroutine — сдвиг по оси за _moveDuration по кривой
```

Синхронизация маятника: фаза на границе каждого пика равна целому числу π, поэтому `cos(фаза) = ±1` — маятник всегда в крайней точке в момент тика. «Wrap»-интервал соединяет последний пик цикла с первым пиком следующего — колебание непрерывно на границах лупа клипа.

## Быстрая настройка в сцене

1. Соберите префаб часов: корень с `PuzzleInteractable` + `PuzzleModeController` + `ClockPuzzleController`, модель часов, стрелки (каждая — объект с `Collider` + `ClockHand`), маятник с `PendulumSwing`. Готовый образец: `Assets/Prefabs/puzzle/Clock/PRF_Clock.prefab`.
2. На каждой стрелке задайте **Hand Type** (`Minute` / `Hour`) и **Rotation Axis** (обычно `(0,0,1)`).
3. На `ClockPuzzleController` настройте **Target Hour** / **Target Minute** и при необходимости **Tolerance Minutes**.
4. Назначьте **Tick Clip** (зацикленный тик; Load Type не Streaming — иначе анализ волновой формы не сработает) и **Chime Clip**.
5. Выберите **Solve Behavior**: часы тикают до решения или «оживают» после него.
6. (Опционально) Включите **Move On Solve** и настройте ось/дистанцию — например, чтобы часы отъехали и открыли тайник.
7. Добавьте `ClockHandHighlight` на стрелки для подсветки при наведении.
8. Установите уникальный **Save ID** на `PuzzleModeController`. Save ID стрелок фиксированы по типу — настраивать их не нужно.

## Важные детали

- Проверка решения — по «минутной шкале»: часовая стрелка возвращает `час × 5`, цель часа тоже переводится в `× 5`, обе сравниваются с допуском на круге из 60 делений.
- Рандомизация стартовой позиции выполняется только если ни одна стрелка не была восстановлена из сохранения (`WasRestoredFromSave`).
- Позиция стрелок сохраняется как индекс шага (`currentStep`) — решение загадки хранится на `PuzzleModeController`, промежуточные положения — через `ISaveable` стрелок.
- Ввод стрелок гейтуется рейкастом: активна только стрелка под курсором, вторая игнорирует ввод, хотя обе находятся в режиме загадки.
- Тик играет через `AudioManager.Play3DLoop` на трансформе маятника; звон — через пул `Play3DOneShot` (маршрутизация в SFX-группу микшера, в отличие от `PlayClipAtPoint`).
- Если **Tick Clip** имеет Load Type Streaming, `AnalyzePeaks` не сможет прочитать сэмплы — маятник перейдёт на фолбэк-частоту.
- При загрузке решённой загадки визуальное состояние восстанавливается без звука: `StartOnSolve` — тик без звона и маятник качается; `StopOnSolve` — маятник остановлен; сдвиг применяется мгновенно, без анимации.
- Решение загадки внутри `ProcessInput` может вызвать выход из режима загадки в том же кадре — `ClockHand.Update` перепроверяет `_puzzleMode.IsActive`, чтобы не перезаписать сброшенный курсор UI.
