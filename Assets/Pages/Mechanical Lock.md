## Обзор

Механический кодовый замок с цилиндрами. Игрок в режиме загадки щёлкает ЛКМ/ПКМ по цилиндрам: ЛКМ вращает цилиндр на один шаг вперёд, ПКМ — назад. Нужно выставить комбинацию символов (по значению на каждом цилиндре). При совпадении всей комбинации играется звук, аниматор открывает замок (стейт `Opening`), выдается награда — предметы по одному через `ItemInspector`, и загадка считается решённой. Поддерживается любое число цилиндров и символов на цилиндре.

## Компоненты

### `MechanicalLock`

Файл: `Assets/Scripts/Puzzle/MechanicalLock/MechanicalLock.cs`. Главный контроллер замка: ввод, проверка комбинации, анимация открытия, награды. Реализует `ISaveable`. Размещается на корневом объекте загадки вместе с `PuzzleModeController`.

**Combination Settings**

| Полe                   | Тип    | Описание                                                                       | Default            |
| ------------------------ | -------- | ------------------------------------------------------------------------------------ | -------------------- |
| `Correct Combination`    | int[]    | Правильная комбинация — нулевой индекс символа на каждом цилиндре                      | `{1, 2, 3, 4, 5}`    |

**Save**

| Полe      | Описание                                                                     | Default |
| ----------- | ---------------------------------------------------------------------------------- | ------- |
| `Save ID`   | Уникальный ID для сохранения состояний цилиндров (Context Menu → Generate Save ID)  | —       |

**References**

| Полe              | Описание                                                      | Default                 |
| ------------------- | ------------------------------------------------------------------- | ------------------------- |
| `Puzzle Controller` | `PuzzleModeController` режима загадки                                | `GetComponent` в Awake    |
| `Cylinders`         | Массив `LockCylinder` — цилиндры замка                                | —                         |

**Animator**

| Полe                    | Описание                                                   | Default        |
| --------------------------- | ------------------------------------------------------------------ | ---------------- |
| `Lock Animator`             | Animator механизма замка; автопоиск в детях, если не назначен        | автопоиск       |
| `Open Trigger Parameter`    | Имя trigger-параметра для запуска анимации открытия                 | `"OpenLock"`     |
| `Open State Name`           | Имя стейта открытия (контроллер опрашивает его завершение)          | `"Opening"`      |

**Audio**

| Полe         | Описание                            | Default |
| --------------- | ----------------------------------------- | ------- |
| `Open Clip`     | Звук открытия замка                        | —       |
| `Open Volume`   | Громкость звука открытия (0–1)             | `1`     |

**Rewards**

| Полe           | Описание                                                                       | Default |
| ----------------- | -------------------------------------------------------------------------------------- | ------- |
| `Reward Items`    | `ItemData[]` — предметы, выдаваемые в инвентарь после решения (по одному через осмотр)  | —       |

### `LockCylinder`

Файл: `Assets/Scripts/Puzzle/MechanicalLock/LockCylinder.cs`. Один цилиндр замка. Шаг угла вычисляется автоматически: `−360 / SymbolCount` градусов за клик.

**Rotation Settings**

| Полe            | Тип     | Описание                                                      | Default   |
| ----------------- | --------- | ------------------------------------------------------------------- | ----------- |
| `Symbol Count`    | int       | Количество символов на цилиндре — определяет шаг угла               | `10`        |
| `Current Index`   | int       | Текущий нулевой индекс символа (для начальной настройки)            | `0`        |
| `Rotation Axis`   | Vector3   | Локальная ось вращения цилиндра                                     | `(0,1,0)`   |

**Audio**

| Полe           | Описание                          | Default |
| ----------------- | ----------------------------------------- | ------- |
| `Rotate Sound`    | Звук при каждом повороте цилиндра         | —       |

Свойства: `SymbolCount`, `CurrentValue` (текущий индекс символа). Публичные методы: `Rotate(bool clockwise)` и `SetValue(int)` (для восстановления из сейва).

## Логика работы

```
Старт (MechanicalLock.Start)
  → Загадка уже решена (из сейва) → RestoreSolvedState():
      Animator.Play(_openStateName, 0, 1) — аниматор перематывается в конец Opening
  → Иначе → RandomizeCylinders():
      случайные значения всем цилиндрам; если случайно выпала правильная
      комбинация — перемешать заново

Игрок в режиме загадки (Update)
  → Первый кадр активности пропускается, чтобы клик взаимодействия
    не повернул цилиндр
  → ЛКМ / ПКМ → рейкаст из камеры → LockCylinder под курсором?
      → ЛКМ: Rotate(true) — индекс −1 (шаг вперёд)
      → ПКМ: Rotate(false) — индекс +1 (шаг назад)
      → звук Rotate Sound, плавная ротация к целевому углу (RotateTowards)
      → CheckCombination()

CheckCombination()
  → количество цилиндров == длине комбинации
  → CurrentValue каждого цилиндра == Correct Combination[i]
  → Совпало → Solve()

Solve()
  → звук Open Clip
  → PlayOpenAnimationThenFinish():
      Animator.SetTrigger("OpenLock")
      → ожидание входа в стейт Opening (таймаут 10 с)
      → ожидание normalizedTime >= 1 (анимация доиграла)
  → FinishSolve():
      → GrantRewardItemsRoutine(): каждый Reward Item показывается через
        ItemInspector один за другим; после подтверждения игроком —
        AddItem в инвентарь (пропускаются уже имеющиеся; переполнение — warning)
      → SaveManager.Save()
      → _puzzleController.SetSolved() — выход из режима загадки
```

## Быстрая настройка в сцене

1. Соберите замок: корень с `PuzzleInteractable` + `PuzzleModeController` + `MechanicalLock`.
2. Создайте дочерние объекты-цилиндры с `LockCylinder` и Collider (кликабельные). Назначьте их в массив **Cylinders**.
3. На каждом цилиндре задайте **Symbol Count** и **Rotation Axis**, назначьте **Rotate Sound**.
4. На `MechanicalLock` задайте **Correct Combination** — нулевые индексы символов (по умолчанию `{1,2,3,4,5}`).
5. Настройте Animator замка: trigger `OpenLock`, стейт `Opening` (назначьте Animator в **Lock Animator** или оставьте автопоиск).
6. Назначьте **Open Clip**.
7. (Опционально) Заполните **Reward Items** — предметы, выдаваемые после открытия.
8. Установите уникальный **Save ID** (Context Menu → Generate Save ID).

## Важные детали

- Проверка комбинации требует **точного равенства** длины массива цилиндров и длины `Correct Combination` — при несовпадении проверка не выполняется.
- Рандомизация начальных значений **гарантированно не даёт** готовое решение: если случайно выпала правильная комбинация, цилиндры перемешиваются повторно.
- ЛКМ и ПКМ дают противоположные направления вращения — ошибку можно откатить без полного оборота.
- Первый кадр режима загадки игнорируется вводом (`_wasActiveLastFrame`): клик по `PuzzleInteractable`, вошедший в режим, не поворачивает цилиндр.
- Во время анимации открытия (`_isProcessing`) ввод отключён.
- Награда выдаётся **после доигрывания анимации**, по одному предмету через `ItemInspector.BeginInspection` — игрок подтверждает получение; предметы, уже лежащие в инвентаре, пропускаются.
- Сохраняются только значения цилиндров (`cylinderValues`); факт решения хранится на `PuzzleModeController`. При загрузке решённого замка аниматор перематывается в конец стейта `Opening` — звук не повторяется.
- Пропуск ввода, опрос стейта и ожидание анимации имеют таймаут 10 с (`AnimationTimeout`) — защита от зацикливания при неправильном Animator Controller.
