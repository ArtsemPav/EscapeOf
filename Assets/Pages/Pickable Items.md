Предмет — объект в мире, который игрок может подобрать и положить в инвентарь. При взаимодействии открывается панель 3D-осмотра (если задан `inspectionPrefab`) или включён режим inspect-only — читаемое превью без подбора.

## Компонент `PickableItem`

**Скрипт:** `Assets/Scripts/Inventory/PickableItem.cs`. Реализует `IInteractable` и `ISaveable` (`RequireComponent(Collider)`).

### Параметры Inspector


| Поле                   | Описание                                                                                                                                       |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `Item Data`            | Ссылка на `ItemData` (обязательна — без неё взаимодействие игнорируется с предупреждением)                                                     |
| `Preview Sound`        | Звук-превью в момент клика по предмету (до открытия инспекции/подбора)                                                                         |
| `Preview Sound Volume` | Громкость звука-превью (по умолчанию 1)                                                                                                        |
| `Inspect Only`         | Предмет можно только осмотреть (`ItemInspector.BeginWorldPreview`): не попадает в инвентарь и не удаляется из сцены, не регистрируется в сейве |
| `Crosshair Mode`       | Иконка прицела (по умолчанию `Hand`)                                                                                                           |
| `Save Id`              | Стабильный ID для сейв-системы; контекстное меню компонента → **Generate Save ID** (GUID)                                                      |


Событие `OnPickedUp` — срабатывает при подборе (до уничтожения объекта).

### Сохранение

`ISaveable` сериализует флаг `collected`. При загрузке собранный предмет уничтожает себя. Подбор (`NotifyPickedUp()`) ставит флаг и вызывает `SaveManager.Save()`. Собранные предметы остаются в реестре SaveManager, чтобы данные не потерялись в дебаунс-окне.

## Шаг 1 — Создать ItemData

`ItemData` — ScriptableObject (меню **Create > Inventory > Item Data**), файл `Assets/Scripts/Inventory/ItemDataSO.cs`. Поля — см. [@ id="/Pages/Private/Inventory System.md" label="Inventory System"].


| Поле                  | Описание                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------- |
| **Item Name**         | Название предмета (показывается в инвентаре и при осмотре)                               |
| **Description**       | Описание — текст, который игрок читает при осмотре                                       |
| **Item Id**           | Стабильный ID сейв-системы (по умолчанию — имя ассета)                                   |
| **Icon**              | Иконка в инвентаре (Sprite)                                                              |
| **Inspection Prefab** | 3D-модель для вращения при осмотре. Если не задан — предмет подбирается сразу без панели |
| **Disable Shimmer**   | Отключить мерцающую подсказку над этим предметом                                         |


## Шаг 2 — Создать 3D-объект в сцене

1. Добавь 3D-модель предмета в сцену (или используй готовый GameObject)
2. Добавь компонент `PickableItem`
3. Назначь созданный `ItemData` в поле **Item Data**
4. Убедись, что объект находится на слое **Interactable Layer**
5. На объекте должен быть **Collider** — без него игрок не сможет его «нащупать»
6. Для уникальных сюжетных предметов заполни `Save Id` (Generate Save ID)

## Предметы внутри ящиков и контейнеров

Если предмет лежит внутри ящика (дочерний объект `DrawerDrag`), соблюдай следующую иерархию слоёв:

```
cupboard_drawer   ← DrawerDrag, Interactable Layer
└── FlashLight    ← PickableItem, Interactable Layer
```

Корпус самого контейнера (стол, шкаф, полка) должен быть на слое **Default**, а не **Interactable Layer**. Иначе Луч 2 (`FPSController`) не заблокирует взаимодействие сквозь закрытые стенки.

> `IDraggable` в `FPSController` ищется только на **прямо хитнутом объекте**, без подъёма по иерархии. Поэтому `DrawerDrag` на родителе-ящике не перехватывает взаимодействие с предметом внутри.

## Шаг 3 — Настроить Inspection Prefab (опционально)

Если хочешь, чтобы игрок мог осмотреть предмет с разных сторон:

1. Создай Prefab из 3D-модели предмета
2. Назначь его в поле `Inspection Prefab` в `ItemData`
3. Убедись, что в проекте существует слой с именем **Inspection** — он нужен для рендеринга превью

## Как это работает

```
Игрок кликает ЛКМ → PickableItem.Interact()
  ├─ проигрывается _previewSound
  ├─ inspectOnly → ItemInspector.BeginWorldPreview — читаемое превью,
  │                объект остаётся в сцене
  ├─ есть inspectionPrefab → ItemInspector.BeginInspection — 3D-панель
  │    ├─ Игрок крутит предмет (ЛКМ + drag)
  │    └─ подтверждение (ConfirmPickup) → NotifyPickedUp() + Save()
  │       → предмет в инвентарь, объект уничтожается
  │       (CancelInspection тоже подтверждает — отмены подбора нет)
  └─ нет inspectionPrefab и нет ItemInspector → предмет сразу в инвентарь
       (проверяется IsFull: если мест нет — объект остаётся в сцене)

Предмет в инвентаре → ЛКМ на слоте
  └─ InventoryItemPreview показывает 3D-превью встроенно в правой панели инвентаря
       ├─ Игрок крутит предмет (ЛКМ + drag по области превью)
       └─ Превью очищается при закрытии инвентаря
```

Пока панель инспекции открыта, `UIManager` управляет курсором (`CursorLockMode.Confined`) и блокирует взаимодействие. При закрытии — управление возвращается.

## Shimmer — мерцающая подсказка

Над предметом каждые `shimmerInterval` секунд (20) вылетает частица из `GameConfig.shimmerPrefab` (назначается на `UIManager`), пока игрок в пределах `shimmerRange` (10 м). Глобально отключается флагом `GameConfig.shimmerEnabled` или per-item флагом `ItemData.disableShimmer`.

## Текст подсказки

`GetInteractText()` возвращает просто `ItemData.itemName`. Поле `GameConfig.pickUpPrefix` («Взять») определено в конфиге, но в текущем коде префиксом не используется — подсказку формирует `InteractionUI` из `GetInteractText()`.
