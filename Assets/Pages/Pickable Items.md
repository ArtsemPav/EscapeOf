Предмет — объект в мире, который игрок может подобрать и положить в инвентарь. При взаимодействии открывается панель 3D-осмотра (если задан `inspectionPrefab`).

## Шаг 1 — Создать ItemData

`ItemData` — ScriptableObject, хранящий все данные о предмете.

1. В Project щёлкни правой кнопкой → **Create → Inventory → Item Data**
2. Задай поля:


| Поле                  | Описание                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------- |
| **Item Name**         | Название предмета (показывается в инвентаре и при осмотре)                               |
| **Description**       | Описание — текст, который игрок читает при осмотре                                       |
| **Icon**              | Иконка в инвентаре (Sprite)                                                              |
| **Inspection Prefab** | 3D-модель для вращения при осмотре. Если не задан — предмет подбирается сразу без панели |
| **Is Unique**         | Если включено — нельзя подобрать второй такой же предмет                                 |


## Шаг 2 — Создать 3D-объект в сцене

1. Добавь 3D-модель предмета в сцену (или используй готовый GameObject)
2. Добавь компонент `PickableItem`
3. Назначь созданный `ItemData` в поле **Item Data**
4. Убедись, что объект находится на слое **Interactable Layer**
5. На объекте должен быть **Collider** — без него игрок не сможет его "нащупать"

## Предметы внутри ящиков и контейнеров

Если предмет лежит внутри ящика (дочерний объект `DrawerDrag`), соблюдай следующую иерархию слоёв:

```
cupboard_drawer   ← DrawerDrag, Interactable Layer
└── FlashLight    ← PickableItem, Interactable Layer
```

Корпус самого контейнера (стол, шкаф, полка) должен быть на слое **Default**, а не **Interactable Layer**. Иначе Луч 2 (`FPSController`) не заблокирует взаимодействие сквозь закрытые стенки.

> `IDraggable` в `FPSController` ищется только на **прямо хитнутом объекте**, без подъёма по иерархии. Поэтому `DrawerDrag` на родителе-ящике не перехватывает взаимодействие с предметом внутри.

## Шаг 3 — Настроить Inspection Prefab (опционально)

Если хочешь, чтобы игрок мог осмотреть предмет с разных сторон:

1. Создай Prefab из 3D-модели предмета
2. Назначь его в поле `Inspection Prefab` в `ItemData`
3. Убедись, что в проекте существует слой с именем **Inspection** — он нужен для рендеринга превью

## Как это работает

```
Игрок нажимает E → PickableItem.Interact()
  └─ есть inspectionPrefab → ItemInspector показывает 3D-панель
       ├─ Игрок крутит предмет (ЛКМ + drag)
       └─ E / Escape → предмет попадает в инвентарь, объект в сцене уничтожается
  └─ нет inspectionPrefab → предмет сразу попадает в инвентарь

Предмет в инвентаре → ЛКМ на слоте
  └─ InventoryItemPreview показывает 3D-превью встроенно в правой панели инвентаря
       ├─ Игрок крутит предмет (ЛКМ + drag по области превью)
       └─ Превью очищается при закрытии инвентаря
```

Пока панель инспекции открыта, `UIManager` автоматически блокирует движение игрока и показывает курсор. При закрытии — управление возвращается.

## Текст подсказки

Текст `"Взять [Название]"` формируется автоматически из `GameConfig.pickUpPrefix` и `ItemData.itemName`. Чтобы изменить слово `"Взять"` для всей игры сразу — открой `GameConfig` и поменяй поле **Pick Up Prefix**.
