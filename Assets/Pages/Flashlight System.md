Система фонарика: переключение режимов происходит **автоматически** по содержимому инвентаря (сменные линзы — например, UV). Скрытые надписи на стенах (`HiddenWallSign`) видны только в луче фонарика в нужном режиме; объекты `HiddenInUvLight` наоборот исчезают под UV-светом.

Предметы-линзы подбираются через стандартный инвентарь — см. [@ id="/Pages/Private/Pickable Items.md" label="Pickable Items"] и [@ id="/Pages/Private/Inventory System.md" label="Inventory System"].

---

## Структура файлов

```
Assets/Scripts/Flashlight/
├── FlashlightConfig.cs      # SO FlashlightConfig + enum FlashlightMode + FlashlightState/ModeConfig
├── FlashlightController.cs  # Singleton — логика включения, режимов, сейва, проксимити-димминга
├── FlashlightLagFollow.cs   # MonoBehaviour — плавное следование источника света за камерой
├── HiddenInUvLight.cs       # MonoBehaviour — деактивирует объект под UV-светом
└── HiddenWallSign.cs        # MonoBehaviour — скрытая надпись на стене

Assets/Shaders/
└── HiddenWallSign.shader    # URP Unlit шейдер — конус + фейды + HDR emission + flood
```

## Данные — `FlashlightConfig` (ScriptableObject)

Создаётся через **Create > Game > Flashlight Config**.

### `FlashlightMode` (enum)

`Normal`, `UV`. Новые линзы = новые значения enum.

### `FlashlightState`

Параметры света одного состояния: `intensity`, `range` (20), `spotAngle` (60), `color`.

### `FlashlightModeConfig`


| Поле            | Описание                                                                           |
| --------------- | ---------------------------------------------------------------------------------- |
| `Mode`          | Идентификатор режима (`Normal`, `UV`)                                              |
| `Required Item` | `InventoryCondition` — условие наличия линзы в инвентаре. `null` = всегда доступен |
| `On State`      | Параметры света (`FlashlightState`) когда фонарик включён в этом режиме            |


### Параметры `FlashlightConfig`


| Поле                  | По умолчанию | Описание                                                                                                                          |
| --------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `Operating Condition` | —            | Условие работы фонарика вообще (например, заряженная батарейка в инвентаре)                                                       |
| `Modes`               | —            | Массив режимов. Автодетект идёт **с конца массива** — последний подходящий режим побеждает; режимы с `null` requiredItem — фолбэк |
| `Transition Speed`    | `8`          | Скорость плавного изменения яркости при включении/выключении (ед/сек)                                                             |

## Логика — `FlashlightController`

Компонент на GameObject'е фонарика (`RequireComponent(Light)`). Singleton (`Instance`), реализует `ISaveable` (SaveId `flashlight` — сохраняется только `isOn`).

### Управление


| Клавиша | Действие                                   |
| ------- | ------------------------------------------ |
| `F`     | Включить / выключить фонарик (`TryToggle`) |


Ручного переключения режимов нет: активный режим определяется автоматически в `DetectAndApplyMode()` при каждом `OnInventoryChanged` — массив `modes` сканируется в обратном порядке, активируется первый подходящий режим (у которого `requiredItem` выполнен или `null`).

### Публичные члены


| Член                                         | Описание                                                                        |
| -------------------------------------------- | ------------------------------------------------------------------------------- |
| `FlashlightMode CurrentMode`                 | Текущий активный режим                                                          |
| `bool IsOn`                                  | Включён ли фонарик                                                              |
| `bool IsLocked { get; set; }`                | Блокирует переключение (ставит `PuzzleModeController` на время пазла)           |
| `event Action<FlashlightMode> OnModeChanged` | Срабатывает при включении, выключении и смене режима                            |
| `TryToggle()`                                | Переключение; требует `operatingCondition`                                      |
| `ForceOff()` / `ForceOn()`                   | Принудительное вкл/выкл без звука (PuzzleModeController)                        |
| `ForceOffTemporarily()` / `ForceOffHard()`   | Выключение с запоминанием состояния (horror-события); Hard — мгновенный блэкаут |
| `RestoreAfterForcedOff()`                    | Пауза → серия миганий → плавное включение (если был включён)                    |
| `DimTemporarily(dimScale, duration)`         | Временное приглушение яркости (паутина); стыкуется — берётся более тёмный скейл |


### Параметры Inspector

**Аудио**


| Поле              | По умолчанию | Описание                                                                                                 |
| ----------------- | ------------ | -------------------------------------------------------------------------------------------------------- |
| `Toggle Clip`     | —            | Звук включения/выключения                                                                                |
| `Toggle Volume`   | `0.8`        | Громкость переключения (0–1)                                                                             |
| `Sound Condition` | —            | `InventoryCondition` для звука клика (все варианты фонарика). `null` — звук только при реальном вкл/выкл |


**Proximity Dimming** — фонарик автоматически тускнеет у поверхностей перед носом: веер из 5 лучей (большинство должно попасть), smooth-damp без мерцания.


| Поле                     | По умолчанию | Описание                                                               |
| ------------------------ | ------------ | ---------------------------------------------------------------------- |
| `Proximity Ray Origin`   | —            | Луч из камеры (не из фонарика); fallback `Camera.main`                 |
| `Proximity Range`        | `1.2`        | Дистанция обнаружения препятствия (м)                                  |
| `Proximity Min Scale`    | `0.3`        | Минимальная доля яркости в упор                                        |
| `Proximity Falloff`      | `2`          | Степень кривой затухания (1 = линейно)                                 |
| `Proximity Smooth Speed` | `12`         | Скорость сглаживания (выше — резче)                                    |
| `Probe Fan Half Angle`   | `10`         | Полуугол веера лучей (защита от ложных срабатываний о лестницы/стойки) |
| `Proximity Mask`         | `Everything` | Слои луча                                                              |


**Hard Off Restore** — восстановление после horror-выключения (`ForceOffHard`).


| Поле                        | По умолчанию | Описание                      |
| --------------------------- | ------------ | ----------------------------- |
| `_hardOffRestoreDelay`      | `2` с        | Пауза перед мерцанием         |
| `_hardOffFlickerDuration`   | `1.2` с      | Длительность серии миганий    |
| `_hardOffFlickerCount`      | `4`          | Число миганий                 |
| `_hardOffFlickerBrightness` | `0.6`        | Доля яркости во время миганий |


### Сохранение и поведение при потере предмета

- **ISaveable:** `GetSaveData` сериализует `isOn`; `LoadSaveData` применяет состояние в `Start()` — без звука и без повторного сейва, и только если `operatingCondition` всё ещё выполняется.
- При изменении инвентаря (`OnInventoryChanged`) режим переопределяется, и если фонарик горит, а `operatingCondition` перестал выполняться (батарейка израсходована) — фонарик автоматически гаснет.

## Плавное следование — `FlashlightLagFollow`

На GameObject'е фонарика (НЕ ребёнок камеры). В `LateUpdate` (после поворота камеры FPSController) позиция следует за камерой быстро, поворот — с инерцией, создавая «вес» фонарика.


| Поле                    | По умолчанию | Описание                                       |
| ----------------------- | ------------ | ---------------------------------------------- |
| `Camera Transform`      | —            | Ссылка на камеру                               |
| `Rotation Follow Speed` | `6`          | Скорость догона поворота (меньше = больше лаг) |
| `Position Follow Speed` | `14`         | Скорость следования позиции (быстрее поворота) |

## Скрытые надписи — `HiddenWallSign`

Компонент на GameObject'е со `SpriteRenderer`. Надпись невидима по умолчанию и появляется только когда фонарик включён и активен нужный режим. Шейдер `Custom/HiddenWallSign` вычисляет для каждого пикселя попадание в конус прожектора и применяет три слоя затухания.

### Параметры Inspector

**Основные**


| Поле                   | По умолчанию                    | Описание                                                                                   |
| ---------------------- | ------------------------------- | ------------------------------------------------------------------------------------------ |
| `Visible In Mode`      | `UV`                            | Режим фонарика, при котором надпись видна                                                  |
| `Edge Softness`        | `0.05`                          | Мягкость границы конуса (0 = жёсткий обрез, 0.12 = очень мягкий)                           |
| `Radial Falloff`       | `1.5`                           | Затухание от центра луча к краю (1 = линейно, 2+ = яркое пятно в центре)                   |
| `Max Visible Distance` | `2` м                           | Дистанция, на которой надпись становится едва заметной                                     |
| `Emission Color`       | Яркий синий (HDR `(0, 0.5, 2)`) | Цвет свечения надписи. HDR-пикер — значения выше `1.0` активируют Bloom                    |
| `Emission Intensity`   | `2`                             | Множитель яркости (0–10). Значения выше `1` подхватываются Bloom; `4–6` — выраженный ореол |


Публичный метод `SetForcedVisible(float amount)` — делает надпись видимой без фонарика (0–1, маски конуса/дистанции игнорируются; используется UV-лампами в катсценах).

### Как работает шейдер

```
Для каждого пикселя спрайта:

1. coneMask   = smoothstep у границы конуса → 0 снаружи, 1 внутри
2. radialFade = pow((cosAngle - edgeCos) / (1 - edgeCos), falloff)
               → 0 на краю конуса, 1 в центре луча
3. distFade   = lerp(1.0, minDistAlpha, saturate(dist/maxDist - 1))
               → 1 вблизи, minDistAlpha на максимальной дистанции
4. floodAmount — принудительная видимость из SetForcedVisible (маски игнорируются)

alpha  = texAlpha × coneMask × radialFade × distFade
rgb    = texColor × EmissionColor × EmissionIntensity × radialFade × distFade
```

Все параметры передаются через `MaterialPropertyBlock` — нет инстансинга материалов, нет аллокаций.

### Bloom

Свечение работает за счёт URP Bloom в Volume Profile сцены (`Assets/Settings/SampleSceneProfile`). Если ореол слишком широкий или слишком слабый:


| Параметр Bloom | Эффект                                                     |
| -------------- | ---------------------------------------------------------- |
| `Threshold`    | Опусти до `0.8–1.0`, чтобы Bloom ловил менее яркие пиксели |
| `Intensity`    | Увеличь, если ореол слабый                                 |
| `Scatter`      | Уменьши, если ореол слишком размазан                       |

## Объекты, исчезающие под UV — `HiddenInUvLight`

Инверсия `HiddenWallSign`: деактивирует GameObject, пока фонарик включён в указанном режиме (`hiddenInMode`, по умолчанию `UV`); при выключении или смене режима объект появляется снова. Скрипт подписывается на `OnModeChanged` даже пока объект неактивен — всегда «возвращается», когда свет уходит.

## Как добавить новую линзу

1. Добавь значение в `enum FlashlightMode` в `FlashlightConfig.cs` (например `Green`)
2. В `FlashlightConfig` asset добавь элемент в массив `Modes`:
   - `Mode = Green`
   - `Required Item` = `InventoryCondition` с предметом-линзой
   - `On State` — цвет и параметры света
3. Создай `ItemData` для линзы и размести его в сцене через `PickableItem` — см. [@ id="/Pages/Private/Pickable Items.md" label="Pickable Items"]

Режим определяется автоматически: как только линза появляется в инвентаре, фонарик переходит в соответствующий режим. Помни: при автодетекте последний подходящий режим в массиве побеждает.

## Как добавить скрытую надпись

1. Создай GameObject на стене
2. Добавь компонент `SpriteRenderer`, назначь спрайт
3. Добавь компонент `HiddenWallSign`
4. Заполни в Inspector:
   - `Visible In Mode` — нужный режим
5. Настрой `Emission Color` и `Emission Intensity` под нужный стиль свечения

```
Wall (MeshRenderer)
└── HiddenSign          # SpriteRenderer + HiddenWallSign
```

## Как добавить режим без предмета (всегда доступный)

В элементе массива `Modes` оставь поле `Required Item` пустым (`null`). Такой режим всегда доступен и служит фолбэком при автодетекте.
