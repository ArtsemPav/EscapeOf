Система фонарика поддерживает переключение режимов через сменные линзы (синяя, красная, UV). Каждый режим меняет цвет и параметры света. Скрытые надписи на стенах (`HiddenWallSign`) видны только в луче фонарика и только в нужном режиме.

Предметы-линзы подбираются через стандартный инвентарь — см. [@ id="/Pages/Private/Pickable Items.md" label="Pickable Items"] и [@ id="/Pages/Private/Inventory System.md" label="Inventory System"].

---

## Структура файлов

```
Assets/Scripts/Flashlight/
├── FlashlightConfig.cs      # ScriptableObject — все параметры фонарика
├── FlashlightController.cs  # MonoBehaviour — логика включения и режимов
├── FlashlightLagFollow.cs   # MonoBehaviour — плавное следование источника света за камерой
└── HiddenWallSign.cs        # MonoBehaviour — скрытая надпись на стене

Assets/Shaders/
└── HiddenWallSign.shader    # URP Unlit шейдер — конус + фейды + HDR emission
```

## Данные — `FlashlightConfig` (ScriptableObject)

Создаётся через **Assets > Create > Game > Flashlight Config**.

### `FlashlightState`

Описывает параметры света для одного состояния.


| Поле         | Описание                |
| ------------ | ----------------------- |
| `Intensity`  | Яркость источника света |
| `Range`      | Радиус действия         |
| `Spot Angle` | Угол конуса (градусы)   |
| `Color`      | Цвет света              |


### `FlashlightModeConfig`

Описывает один режим фонарика (одну линзу).


| Поле            | Описание                                                                           |
| --------------- | ---------------------------------------------------------------------------------- |
| `Mode`          | Идентификатор режима (`Normal`, `Blue`, `Red`, `UV`)                               |
| `Required Item` | `InventoryCondition` — условие наличия линзы в инвентаре. `null` = всегда доступен |
| `On State`      | Параметры света (`FlashlightState`) когда фонарик включён в этом режиме            |


### Параметры `FlashlightConfig`


| Поле                  | Описание                                                                    |
| --------------------- | --------------------------------------------------------------------------- |
| `Operating Condition` | Условие работы фонарика вообще (например, заряженная батарейка в инвентаре) |
| `Modes`               | Массив режимов в порядке переключения. Первый элемент — режим по умолчанию  |
| `Off State`           | Параметры света когда фонарик выключен (общий для всех режимов)             |
| `Transition Speed`    | Скорость плавного изменения яркости при включении/выключении (ед/сек)       |

## Логика — `FlashlightController`

Компонент на GameObject'е фонарика. Требует `Light` на том же GameObject'е.

### Управление


| Клавиша | Действие                                                                |
| ------- | ----------------------------------------------------------------------- |
| `F`     | Включить / выключить фонарик                                            |
| `R`     | Переключить на следующий доступный режим (только когда фонарик включён) |


Режимы, для которых `requiredItem` не выполнен, пропускаются при переключении.

### Публичные члены


| Член                                         | Описание                                             |
| -------------------------------------------- | ---------------------------------------------------- |
| `FlashlightMode CurrentMode`                 | Текущий активный режим                               |
| `bool IsOn`                                  | Включён ли фонарик                                   |
| `event Action<FlashlightMode> OnModeChanged` | Срабатывает при включении, выключении и смене режима |


### Параметры Inspector


| Поле                 | Описание                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Config`             | Ссылка на `FlashlightConfig` asset                                                                         |
| `Toggle Clip`        | Звук включения/выключения                                                                                  |
| `Mode Switch Clip`   | Звук смены режима линзы                                                                                    |
| `Toggle Volume`      | Громкость переключения (`0–1`)                                                                             |
| `Mode Switch Volume` | Громкость смены режима (`0–1`)                                                                             |
| `Sound Condition`    | `InventoryCondition` для воспроизведения звука. Если `null` — звук только когда фонарик реально включается |


### Поведение при потере предмета

Если в рантайме `operatingCondition` перестаёт выполняться (например, предмет использован), фонарик автоматически выключается через подписку на `InventorySystem.OnInventoryChanged`.

## Скрытые надписи — `HiddenWallSign`

Компонент на GameObject'е со `SpriteRenderer`. Надпись невидима по умолчанию и появляется только когда фонарик включён и активен нужный режим.

Шейдер вычисляет для каждого пикселя, попадает ли он в конус прожектора, и применяет три слоя затухания.

### Параметры Inspector

**Основные**


| Поле              | По умолчанию | Описание                                  |
| ----------------- | ------------ | ----------------------------------------- |
| `Visible In Mode` | `Blue`       | Режим фонарика, при котором надпись видна |
| `Flashlight`      | —            | Ссылка на `FlashlightController` в сцене  |


**Beam Shape — форма видимости**


| Поле             | По умолчанию | Описание                                                                                      |
| ---------------- | ------------ | --------------------------------------------------------------------------------------------- |
| `Edge Softness`  | `0.05`       | Мягкость границы конуса в косинусном пространстве. `0` = жёсткий обрез, `0.12` = очень мягкий |
| `Radial Falloff` | `1.5`        | Скорость затухания от центра к краю луча. `1` = линейное, `2+` = резкое яркое пятно в центре  |


**Distance Fade — затухание по дистанции**


| Поле                   | По умолчанию | Описание                                                                                                    |
| ---------------------- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| `Max Visible Distance` | `2` м        | Дистанция, на которой надпись становится едва заметной                                                      |
| `Min Dist Alpha`       | `0.04`       | Минимальная прозрачность за пределами `Max Visible Distance`. `0` = полностью невидима, `0.05` = едва видна |


**Emission / Glow — свечение**


| Поле                 | По умолчанию      | Описание                                                                                             |
| -------------------- | ----------------- | ---------------------------------------------------------------------------------------------------- |
| `Emission Color`     | Яркий синий (HDR) | Цвет свечения надписи. HDR-пикер — значения выше `1.0` активируют Bloom                              |
| `Emission Intensity` | `2`               | Множитель яркости. Значения выше `1` подхватываются Bloom в Volume Profile. `4–6` — выраженный ореол |


### Как работает шейдер

```
Для каждого пикселя спрайта:

1. coneMask   = smoothstep у границы конуса → 0 снаружи, 1 внутри
2. radialFade = pow((cosAngle - edgeCos) / (1 - edgeCos), falloff)
               → 0 на краю конуса, 1 в центре луча
3. distFade   = lerp(1.0, minDistAlpha, saturate(dist/maxDist - 1))
               → 1 вблизи, minDistAlpha на максимальной дистанции

alpha  = texAlpha × coneMask × radialFade × distFade
rgb    = texColor × EmissionColor × EmissionIntensity × radialFade × distFade
```

Шейдер использует `MaterialPropertyBlock` — нет инстансинга материалов, нет аллокаций.

### Bloom

Свечение работает за счёт URP Bloom в Volume Profile сцены (`Assets/Settings/SampleSceneProfile`). Если ореол слишком широкий или слишком слабый:


| Параметр Bloom | Эффект                                                    |
| -------------- | --------------------------------------------------------- |
| `Threshold`    | Опусти до `0.8–1.0` чтобы Bloom ловил менее яркие пиксели |
| `Intensity`    | Увеличь если ореол слабый                                 |
| `Scatter`      | Уменьши если ореол слишком размазан                       |

## Как добавить новую линзу

1. Добавь значение в `enum FlashlightMode` в `FlashlightConfig.cs` (например `Green`)
2. В `FlashlightConfig` asset добавь элемент в массив `Modes`:
  - `Mode = Green`
  - `Required Item` = `InventoryCondition` с предметом-линзой
  - `On State` — цвет и параметры света
3. Создай `ItemData` для линзы и разместили его в сцене через `PickableItem` — см. [@ id="/Pages/Private/Pickable Items.md" label="Pickable Items"]

---

## Как добавить скрытую надпись

1. Создай GameObject на стене
2. Добавь компонент `SpriteRenderer`, назначь спрайт
3. Добавь компонент `HiddenWallSign`
4. Заполни в Inspector:
  - `Visible In Mode` — нужный режим
  - `Flashlight` — ссылка на `FlashlightController`
5. Настрой `Emission Color` и `Emission Intensity` под нужный стиль свечения

```
Wall (MeshRenderer)
└── iKenherit          # SpriteRenderer + HiddenWallSign
```

---

## Как добавить режим без предмета (всегда доступный)

В элементе массива `Modes` оставь поле `Required Item` пустым (`null`). Такой режим всегда доступен для переключения.
