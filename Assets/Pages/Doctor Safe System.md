## Обзор

Загадка «Сейф врача». Игрок в режиме загадки вращает кодовый диск сейфа мышью (дискретные щелчки по 3.6° = 100 позиций на оборот) и вводит комбинацию из нескольких шагов: каждое значение достигается вращением в строго заданном направлении. Слушая фонограмму с надетым стетоскопом, игрок по звуку определяет правильные шаги. При ошибочном повороте диск сбрасывается двумя холостыми оборотами. После ввода всей комбинации запускается последовательность: выход из режима загадки → поворот ручки → дверь сейфа отпирается и открывается.

## Компоненты

### `LockDial`

Файл: `Assets/Scripts/Puzzle/DoctorSafe/LockDial.cs`. Кодовый диск. Реализует `ISaveable`, `IPuzzleDropHandler`, `IPuzzleDropTarget`, `IPuzzleDropHoverHandler`. Требует `Collider` на объекте (слоя `PuzzleInteractable`) и `PuzzleModeController` на объекте или в родителях.

| --------- | ------------------------------------------------ | ------- |
| `Save ID` | Уникальный ID для системы сохранений             | —       |

**References**

| Поле          | Описание                                                | Default                        |
| ------------- | ----------------------------------------------------------- | -------------------------------- |
| `Puzzle Mode` | `PuzzleModeController` режима загадки                       | `GetComponentInParent` в Awake  |

**Rotation**

| Поле                       | Тип     | Описание                                                      | Default   |
| -------------------------- | ------- | --------------------------------------------------------------- | --------- |
| `Step Angle`               | float   | Градусов на дискретный шаг. 3.6° = 100 позиций на оборот        | `3.6`     |

**Combination Settings**

| -------------------- | ------------- | ------------------------------------------------------------------------------- | --------- |

| `Random Max Value`   | int           | Инклюзивный максимум для случайных значений                                      | `99`      |

При рандомизации значения случайны, а направления чередуются (CW → CCW → CW → …) — направление первого шага случайное.

## Логика работы

```
Старт (LockDial.Awake)
  → RandomizeOnStart и не решено → RandomizeCombination()
      (случайные значения, чередующиеся направления)

Вход в режим загадки (OnPuzzleEntered)
  → коллайдер диска включается (мог быть выключен RoomController.Lock())
  → стетоскоп применён? → фон приглушается, включается Puzzle Background Layer

Игрок вращает диск мышью
  → Рейкаст по слою PuzzleInteractable: захват только над диском
  → HandleDrag(): угол мыши вокруг центра диска, аккумулятор шага
  → Каждые _stepAngle → RotateDiscrete(±1):
      → Tick Sound (всегда)
      → со стетоскопом: значение == Target Value текущего шага
        и направление совпадает → Correct Step Sound (подсказка)

Игрок отпускает ЛКМ → CheckCombination()
  → значение и направление последнего «захода» совпали с шагом комбинации
      → _comboProgressIndex++ → все шаги пройдены → Unlock()
  → иначе если поворот превысил _stepAngle × 2 (ComboResetStepMultiplier)
      → ResetDialRoutine(): диск крутится 2 полных оборота с тиками
        и возвращается на шаг 0, прогресс комбинации сбрасывается

Unlock()
  → _isUnlocked = true, ResetUI
  → _onUnlocked.Invoke() → SafeUnlockSequence.StartSequence()
  → _puzzleMode.SetSolved() (выход из режима + сохранение)

SafeUnlockSequence
  → 1. ExitPuzzleMode() немедленно
  → пауза _delayBeforeHandle
  → 2. RotateOnTrigger.TriggerRotation() — ручка поворачивается на Target Angle
      (по завершении поворота — SaveManager.Save())
  → пауза _delayBeforeDoor
  → 3. DoorInteraction.UnlockAndOpen() — дверца отпирается и открывается
```

## Быстрая настройка в сцене

1. Разместите сейф (`Assets/Prefabs/puzzle/DoctorRoomSafe/PRF_DoctorRoomSafeConteiner.prefab`): корень с `PuzzleInteractable` + `PuzzleModeController`, модель сейфа, диск с `LockDial`, ручка с `RotateOnTrigger`, дверца с `DoorInteraction`.
2. На `LockDial`:
  - задайте **Combination** (значения 0–99 и направления шагов) или оставьте **Randomize On Start** включённым;
  - назначьте **Required Item For Audio** — `ItemData` стетоскопа;
  - вставьте **Tick Sound** и **Correct Step Sound** (рекомендуется `Assets/sound/DoctorRoomSafe/S_CorrectStepSound.ogg` и `S_QuietRoomTone.ogg`);
  - назначьте **Stethoscope Visual** (модель стетоскопа, выключенная по умолчанию).
3. Создайте `SafeUnlockSequence` и подключите его `StartSequence()` к событию **On Unlocked** диска.
4. На `RotateOnTrigger` ручки настройте **Rotation Axis** и **Target Angle**.
5. Установите уникальные **Save ID** на `PuzzleModeController`, `LockDial` и `RotateOnTrigger` (у диска и ручки есть Context Menu → Generate Save ID).
6. Убедитесь, что слой `PuzzleInteractable` существует в проекте и назначен коллайдеру диска.

## Важные детали

- **Стетоскоп — опциональный элемент**: без него диск полностью вращается, но звук правильного шага не слышен (`HasRequiredItem` = false). Если `Required Item For Audio` не назначен вообще, аудио-подсказки работают всегда.
- Комбинация проверяется **по завершении перетаскивания**: сравниваются текущее значение диска и направление последнего захода. Направление определяется знаком суммарного дельта-угла drag'а.
- Сброс диска запускается только при значимом неверном повороте (> 2 шагов); мелкие колебания в пределах шага прогресс не затирают.
- Во время `ResetDialRoutine` ввод и плавная ротация блокируются (`_isResetting`).
- Стетоскоп применяется перетаскиванием из `PuzzleInventoryBar` на диск (рейкаст должен попасть в `Collider` диска); подтверждение наведения — ghost-подсказка «на сейф» и показ модели стетоскопа (`SetDragHover`).
- После применения стетоскопа фоновая музыка приглушается и включается слой комнаты; при выходе из режима загадки всё восстанавливается (`MusicDirector.PlayGameMusic`).
- Коллайдер диска включается только в режиме загадки — иначе он перекрывал бы коллайдер `PuzzleInteract` на двери сейфа.
- Сохраняются: позиция диска, факт открытия, применён ли стетоскоп, прогресс комбинации. `RotateOnTrigger` сохраняет факт поворота и мгновенно восстанавливает финальную ротацию при загрузке.
- Коллайдер сейфа должен быть на слое `Default` — рейкасты диска фильтруются строго по слою `PuzzleInteractable`, поэтому корпус не блокирует ввод.
