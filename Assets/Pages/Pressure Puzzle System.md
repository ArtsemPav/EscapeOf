# Pressure Puzzle System

Загадка на давление: игрок переключает рычаги чтобы сбалансировать стрелку циферблата в нейтральную позицию (0°). Поддерживает два режима: мгновенная обратная связь и подтверждение взаимодействием.

---

## Компоненты

### `PressureLever`

Ставится на каждый рычаг. Обрабатывает визуальный поворот, звук и сообщает об изменении состояния в `PressurePuzzle`.

| Поле | Описание |
|---|---|
| `_offValue` | Вклад в давление когда рычаг выключен |
| `_onValue` | Вклад в давление когда рычаг включён |
| `_angleOnDelta` | Дельта поворота по оси Z при переключении в ON |
| `_arrowSmoothSpeed` | Скорость анимации рычага |
| `_toggleClip` | AudioClip при переключении |

### `PressurePuzzle`

Ставится на корневой GameObject загадки. Агрегирует значения рычагов, управляет стрелкой и фиксирует решение.

| Поле | Описание |
|---|---|
| `_arrow` | Transform стрелки внутри циферблата (`screen/arrow`) |
| `_arrowAngleAtMin` | Угол X стрелки при минимальном суммарном давлении |
| `_arrowAngleAtMax` | Угол X стрелки при максимальном суммарном давлении |
| `_arrowSmoothSpeed` | Скорость анимации стрелки (SmoothDamp) |
| `_solveAngleTolerance` | Допуск от 0° в градусах при котором загадка считается решённой (по умолчанию: 10) |
| `_minStartDistanceFraction` | Минимальное стартовое расстояние от решённого угла как доля от полного диапазона. Предотвращает старт рядом с решением |
| `_confirmOnInteract` | Если включено — стрелка обновляется только при взаимодействии с манометром, не при каждом рычаге |
| `_saveId` | Уникальный ID для системы сохранений |
| `_rewardObjects` | GameObject-ы которые активируются при решении (свет, дверь и т.д.) |
| `_onSolved` | UnityEvent срабатывающий один раз при решении |

### `PressureGauge`

Ставится на коллайдер манометра (`screen`). Реализует `IInteractable` — показывает подсказку и вызывает `PressurePuzzle.Confirm()`.

| Поле | Описание |
|---|---|
| `_interactText` | Текст подсказки в прицеле |

## Иерархия в сцене

```
PreasurePuzzel              ← PressurePuzzle
  stick1                    ← PressureLever, Interactable Layer
  stick2
  ...
  screen                    ← PressureGauge
    Plate                   ← MeshCollider, Interactable Layer
    arrow                   ← назначить в PressurePuzzle._arrow
```

---

## Как работает циферблат

Суммарное давление — это сумма текущих значений всех рычагов. Оно маппится в угол X стрелки:

- Все рычаги на минимуме → стрелка в `_arrowAngleAtMin`
- Все рычаги на максимуме → стрелка в `_arrowAngleAtMax`
- **Загадка решена когда стрелка достигает 0° ± `_solveAngleTolerance`**

Стрелка использует `Mathf.SmoothDamp` — плавная анимация независимая от частоты кадров. Компоненты Y и Z эйлеровых углов кэшируются один раз при старте чтобы избежать джиттера из-за gimbal lock.

---

## Режимы взаимодействия

### Реальное время (`_confirmOnInteract = false`)
Стрелка следует за текущей суммой рычагов мгновенно при каждом переключении. Загадка решается автоматически как только выставлена верная комбинация.

### Подтверждение (`_confirmOnInteract = true`)
Стрелка не двигается пока игрок не взаимодействует с манометром (`PressureGauge`). Убирает живую обратную связь и заставляет считать результат мысленно перед фиксацией.

---

## Сохранение

`PressurePuzzle` реализует `ISaveable`. При решении вызывается `SaveManager.Instance.Save()`. При следующей загрузке:

- `LoadSaveData()` устанавливает внутренний флаг **до** `Start()`
- `Start()` видит флаг, пропускает рандомизацию и вызывает `RestoreSolvedState()` — стрелка снапается в 0°, reward-объекты активируются мгновенно, события не вызываются

Задай уникальный `_saveId` в Inspector, например `pressure_puzzle_boilerroom`. Никогда не меняй его после первого сохранения.

## Настройка с нуля

1. Создай корневой GameObject и добавь `PressurePuzzle`
2. Добавь дочерние рычаги с компонентом `PressureLever` на **Interactable Layer**
3. Задай `_offValue` и `_onValue` на каждом рычаге. Используй симметричные значения (например -20 / +20) чтобы середина была 0
4. Назначь Transform `arrow` в поле `PressurePuzzle._arrow`
5. Добавь `PressureGauge` на GameObject `screen`. Убедись что дочерний коллайдер (`Plate`) на **Interactable Layer**
6. Добавь нужные объекты в `_rewardObjects` (свет, дверь и т.д.)
7. Настрой `_arrowAngleAtMin` и `_arrowAngleAtMax` по физическому виду циферблата в сцене. Решённый угол всегда **0°**
8. Отрегулируй `_solveAngleTolerance` (10° — хорошее значение по умолчанию). Допуск должен перекрывать хотя бы одну достижимую комбинацию рычагов
9. Задай уникальный `_saveId` в Inspector

## Поиск валидного решения

С шагом значений кратным 5 угол для комбинации вычисляется как:

```
angle = Lerp(_arrowAngleAtMin, _arrowAngleAtMax,
         InverseLerp(allOffSum, allOnSum, currentTotal))
```

Загадка решена когда `|angle| ≤ _solveAngleTolerance`. Проверяй комбинации в Play mode — консоль выводит диапазон и стартовый угол при запуске:

```
[PressurePuzzle] 6 levers. Range [-90…90]. Solve at 0° ±10°. Start angle: 87.3°
```
