# Требования к ПК — EscapeOf

Оценка на основе анализа проекта: Unity 6000.3, URP (Forward+, Linear + HDR), одна сцена `Game.unity` со всем зданием, Room Visibility System + зонное отключение света.

## Техническая база оценки


| Параметр                     | Значение                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------- |
| Графический API (Windows)    | D3D11 + D3D12                                                                     |
| Цветовое пространство        | Linear + HDR                                                                      |
| MSAA                         | 4x (PC-пресет)                                                                    |
| SSAO                         | Включён (Renderer Feature, GTAO)                                                  |
| Тени                         | 4 каскада, shadowmap 4096, но realtime-тени на лампах отключены (`shadows: None`) |
| Пост-процесс                 | Vignette, Motion Blur, Lens Distortion, Color Grading, Fog                        |
| Объём сцены                  | 5721 MeshRenderer, 3495 коллайдеров, 201 источник света, 227–300 Particle System  |
| Куллинг                      | RoomVisibilityManager (26 комнат) + LightingSystem (зонное выключение света)      |
| Reflection Probes            | 0                                                                                 |
| Графические настройки в игре | Качество, разрешение, лимит FPS, режим окна (`SystemSettings.cs`)                 |


Ключевой вывод: 199 светильников в сцене не проблема — Room Visibility/LightingSystem держат активными ~4–13 ламп на зону. Реальная нагрузка пиксельная: MSAA 4x, SSAO, туман, частицы (пик — пожар в подвале, 19+ эмиттеров WallFire).

## Минимальные требования (720p, 30+ fps, низкий пресет)

- **ОС:** Windows 10 64-bit
- **CPU:** 4 ядра — Intel Core i3-8100 / AMD Ryzen 3 1300X
- **GPU:** GTX 950 / RX 550, 2 GB VRAM (DX11)
- **RAM:** 8 GB
- **Диск:** 2–5 GB, желательно SSD
- **Встроенная графика:** Intel Iris Xe / AMD Vega 8 — 30–50 fps на низких

## Рекомендуемые требования (1080p, 60 fps, пресет PC)

- **ОС:** Windows 10/11 64-bit
- **CPU:** 6 ядер — Intel Core i5-9400 / AMD Ryzen 5 2600
- **GPU:** GTX 1650 Super / RX 570, 4–6 GB VRAM
- **RAM:** 16 GB
- **Диск:** SSD
- **Встроенная графика:** AMD Radeon 780M — 60 fps на низких, 40–50 на средних

## Встроенная графика (ноутбуки)


| iGPU                           | 720p low                 | 1080p        |
| ------------------------------ | ------------------------ | ------------ |
| Intel UHD 620 и старше         | 20–30 fps на минималках  | неиграбельно |
| Intel Iris Xe / AMD Vega 8     | 30–50 fps                | 25–35 fps    |
| AMD Radeon 780M / свежие Ryzen | 60 fps low, 40–50 medium | 30–45 fps    |


Главная нагрузка на iGPU: MSAA 4x, SSAO, туман. Тени не проблема — realtime-тени на лампах отключены.

## Замечания по оптимизации (потенциал)

1. Разрешить Mobile-пресет качества на Standalone — сейчас он исключён (`excludedTargetPlatforms: [Standalone]`), на ПК доступны только PC-пресеты с полным качеством.
2. Пресет «Low» с MSAA Off — наибольший выигрыш на iGPU, при тёмном хоррор-стиле почти незаметен.
3. SSAO Off в минимальном качестве.
4. RenderScale 0.75–0.8 для слабых машин (как в `Mobile_RPAsset`).

## Методика и ограничения

Оценка сделана по настройкам проекта (`PC_RPAsset`, `QualitySettings`, `PC_Renderer`) и составу сцены, без бенчмарков. Не проверено: точные draw calls/setpass, вес бандлов текстур и моделей, реальный FPS на целевом железе. Для точных цифр — Unity Profiler в Play Mode на целевой машине.
