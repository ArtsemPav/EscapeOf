Два вида кодовых замков:

1. **`CodeLock` + `CodeLockUI`** — настенная панель с нумпадом: игрок вводит код, при успехе срабатывает UnityEvent (например, дверь `UnlockAndOpen()`).
2. **`DigitalLockSystem` + `RingCodeIndicator`** — «умный» экран с полем ввода (используется внутри пазлов через `PuzzleModeController`).

## CodeLock — настенный кодовый замок

**Скрипт:** `Assets/Scripts/Interaction/CodeLock.cs`. Реализует `IInteractable` и `ISaveable`.

Взаимодействие — одиночный клик ЛКМ (`UseLMBClick`), иконка прицела `CrosshairMode.Read`. Открывает `CodeLockUI`. После разблокировки замок полностью неинтерактивен (коллайдер отключается).

### Параметры Inspector


| Поле                   | По умолчанию    | Описание                                                                                                           |
| ---------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Randomize On Start** | `true`          | Код генерируется случайно при каждом запуске (`Awake`)                                                             |
| **Code Length**        | `4`             | Количество цифр случайного кода                                                                                    |
| **Secret Code**        | `1234`          | Фиксированный код (если Randomize On Start выключен)                                                               |
| **Interact Text**      | `Ввести код`    | Текст подсказки при взгляде на замок                                                                               |
| **Required Item**      | —               | Предмет, который должен быть в инвентаре чтобы открыть панель. Расходуется при разблокировке (если `consumeOnUse`) |
| **Missing Item Hint**  | `Нужен предмет` | Подсказка `GetBlockedHint()`, если предмета нет                                                                    |
| **Lock UI**            | —               | Компонент `CodeLockUI` с Canvas                                                                                    |
| **Save Id**            | —               | Стабильный ID сейва; контекстное меню → **Generate Save ID**                                                       |


### События


| Событие             | Когда срабатывает                                                            |
| ------------------- | ---------------------------------------------------------------------------- |
| `On Panel Opened`   | Открытие кодовой панели — сюда wire хоррор-эффекты, исчезающие при открытии  |
| `On Unlocked`       | Верный код — сюда wire `DoorInteraction.UnlockAndOpen()`                     |
| `On Unlocked Event` | `GameEvent` (.asset из `Assets/Data/Events/`), поднимается при разблокировке |


### Сохранение

`ISaveable` сериализует `isUnlocked` и активный код (случайный код переживает сессии). При загрузке замок восстанавливает код и, если разблокирован, отключает коллайдер. `OnUnlocked` при загрузке НЕ срабатывает — состояние двери восстанавливается её собственным ISaveable. Разблокировка в игре (`TryUnlock`) — чекпоинт сейва.

### Публичные члены

- `IsUnlocked` — разблокирован ли замок
- `CodeLength` — длина активного кода (управляет числом слотов нумпада)
- `GetCode()` — активный код сессии (для `CodeHintDisplay`)
- `TryUnlock(string)` — проверка кода; при успехе расходует `requiredItem`, поднимает события, отключает коллайдер, сохраняет

## Шаг 1 — Настроить дверь

1. Убедись, что на двери есть `DoorInteraction` с методом `UnlockAndOpen()` — он вызывается когда код верный
2. (Опционально) `DoorAnimator` — если дверь аниматорная

## Шаг 2 — Добавить компонент CodeLock

1. Выбери объект замка в сцене (панель с кнопками, считыватель и т.д.)
2. Добавь компонент `CodeLock`
3. Настрой параметры (таблица выше)
4. Объект — на слое **Interactable Layer**, с коллайдером

## Шаг 3 — Назначить событие OnUnlocked

В компоненте `CodeLock` найди секцию **Events → On Unlocked**:

1. Нажми `+` чтобы добавить обработчик
2. Перетащи объект двери в поле
3. Выбери `DoorInteraction → UnlockAndOpen()`

## Шаг 4 — Разместить подсказку с кодом (CodeHintDisplay)

**Скрипт:** `Assets/Scripts/UI/CodeHintDisplay.cs`

Если код **случайный** (`Randomize On Start = true`), игрок не знает его заранее — нужен объект в сцене, показывающий код.

1. Создай GameObject в сцене (например, лист бумаги на столе)
2. Добавь дочерний **Canvas** в режиме **World Space**, настрой размер
3. Внутри Canvas добавь `TextMeshProUGUI` — поле для кода
4. Добавь компонент `CodeHintDisplay` на родительский GameObject
5. Назначь поля:


| Поле          | Что назначить                                           |
| ------------- | ------------------------------------------------------- |
| **Code Lock** | Компонент `CodeLock` замка, код которого нужно показать |
| **Code Text** | Компонент `TextMeshProUGUI` внутри Canvas               |


При старте (`Start`) `CodeHintDisplay` прочитает текущий код (`CodeLock.GetCode()`) и запишет его в текстовое поле.

## CodeLockUI — панель ввода

**Скрипт:** `Assets/Scripts/UI/CodeLockUI.cs`. Вешается на **Canvas** (не на саму панель), чтобы корутины не умирали при `SetActive(false)` панели.

Поля: `_panel` (панель нумпада), `_displayText` (введённый код — «● _ _ _»), `_displayRect` (для шейка), `_statusText` («Доступ открыт»/«Неверный код»), `_shakeStrength 12`, `_shakeDuration 0.45`.

### Управление при вводе кода


| Кнопка                        | Действие                |
| ----------------------------- | ----------------------- |
| `0–9` (клавиатура или нумпад) | Ввести цифру            |
| `Backspace`                   | Удалить последнюю цифру |
| `Enter` (и нумпад-Enter)      | Подтвердить код         |
| `Escape`                      | Закрыть панель          |


Код подтверждается автоматически через 0.25 с после ввода последней цифры (`AutoSubmit`).

### Поведение

- **Верный код:** тексты и цвет успеха из `GameConfig` (`codeLockSuccessText` «Доступ открыт», `successColor`), пауза 1 с → панель закрывается, `CodeLock.TryUnlock` уже отработал (дверь открылась).
- **Неверный код:** текст ошибки из `GameConfig` (`codeLockWrongText` «Неверный код», `errorColor`), тряска дисплея (`ShakeRoutine`, sine по X с затуханием) → ввод сбрасывается. Попытка логируется (`ProgressLogger`, `puzzle_failed`).
- Панель открывается/закрывается через `UIManager.OpenPanel/ClosePanel`.
- Кнопки нумпада — `NumPadButton`.

### NumPadButton

**Скрипт:** `Assets/Scripts/UI/NumPadButton.cs` (`RequireComponent(Button)`). На каждую кнопку нумпада: поле `_lockUI` (ссылка на `CodeLockUI`) и `_value` — строка: `"0"–"9"` для цифр, `"clear"` для backspace, `"enter"` для подтверждения.

## Тексты и цвета

Тексты «Доступ открыт» / «Неверный код» и цвета (зелёный/красный) настраиваются в `GameConfig` (ассет `Assets/GameConfig.asset`):

- **Code Lock Success Text** / **Code Lock Wrong Text**
- **Success Color** / **Error Color** / **Normal Color**

Изменение применяется ко всем замкам в игре.

## DigitalLockSystem — экран замка в пазлах

**Скрипт:** `Assets/Scripts/Interaction/DigitalLockSystem.cs`

Отдельная система для пазлов: экран с полем ввода (0–9, Enter, Clear), мигающим курсором и fixed-width моноширинным отображением (`<mspace>`; введённые цифры кроме последней показываются звёздочками). Не использует `CodeLock`/`CodeLockUI`.

Параметры Inspector:


| Поле                            | По умолчанию | Описание                                                             |
| ------------------------------- | ------------ | -------------------------------------------------------------------- |
| `_correctCode`                  | `1234`       | Правильная комбинация                                                |
| `_useRandomCode`                | `false`      | Случайный код при старте вместо фиксированного                       |
| `_randomCodeLength`             | `4`          | Длина случайного кода (1–10)                                         |
| `_maxCodeLength`                | `8`          | Максимум вводимых цифр                                               |
| `_solvedText`                   | `SOLVED`     | Текст на экране после решения                                        |
| `_errorText`                    | `ERROR`      | Текст при неверном коде (показывается `_errorDisplayDuration 1.5` с) |
| `_screenText`                   | —            | `TextMeshPro` экрана                                                 |
| `_puzzleController`             | —            | `PuzzleModeController` — при верном коде вызывается `SetSolved()`    |
| `_buttonPressSounds`            | —            | Случайный звук на нажатие цифры/Clear/Enter                          |
| `_successSound` / `_errorSound` | —            | Звуки верного/неверного кода                                         |


Публичное API: `ActiveCode` (текущий код — читает `RingCodeIndicator`), `GenerateRandomCode()`, `ToggleRandomCode()`, `AddDigit(int)`, `Clear()`, `Submit()`.

## RingCodeIndicator — индикатор-кольца

**Скрипт:** `Assets/Scripts/Interaction/RingCodeIndicator.cs`

Визуализирует код `DigitalLockSystem` вращением дочерних колец: цифра N кода → кольцо N, поворот `digit * _degreesPerDigit` вокруг локальной Z.


| Поле                 | По умолчанию | Описание                                                        |
| -------------------- | ------------ | --------------------------------------------------------------- |
| `_degreesPerDigit`   | `30`         | Градусов поворота на единицу цифры                              |
| `_rotationSpeed`     | `0`          | Скорость плавного доворота (°/сек); 0 = мгновенно               |
| `_digitalLockSystem` | —            | Система-источник кода                                           |
| `_rings`             | —            | Кольца по порядку цифр; пусто — автосбор детей с «Ring» в имени |


`ApplyCode()` — перечитать код и выставить целевые повороты (вызывать после перегенерации кода).
