Кодовый замок — объект, который открывает дверь при вводе правильного кода. Поддерживает случайную генерацию кода и опциональное требование предмета.

## Шаг 1 — Настроить дверь

1. Убедись, что на двери есть компонент `DoorAnimator` — он управляет анимацией открытия
2. Дверь должна иметь метод `UnlockAndOpen()` — он вызывается когда код верный

## Шаг 2 — Добавить компонент CodeLock

1. Выбери объект замка в сцене (панель с кнопками, считыватель и т.д.)
2. Добавь компонент `CodeLock`
3. Настрой параметры:


| Поле                   | Описание                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| **Randomize On Start** | Если включено — код генерируется случайно при каждом запуске                               |
| **Code Length**        | Количество цифр в случайном коде (работает только при Randomize On Start)                  |
| **Secret Code**        | Фиксированный код (используется если Randomize On Start выключен)                          |
| **Interact Text**      | Текст подсказки при взгляде на замок                                                       |
| **Required Item**      | Предмет, который должен быть в инвентаре чтобы открыть панель. Оставь пустым если не нужно |
| **Missing Item Hint**  | Текст, который появится если у игрока нет нужного предмета                                 |
| **Lock UI**            | Перетащи сюда компонент `CodeLockUI` с Canvas                                              |


## Шаг 3 — Назначить событие OnUnlocked

В компоненте `CodeLock` найди секцию **Events → On Unlocked**:

1. Нажми `+` чтобы добавить обработчик
2. Перетащи объект двери в поле
3. Выбери `DoorAnimator → UnlockAndOpen()`

## Шаг 4 — Разместить подсказку с кодом (CodeHintDisplay)

Если код **случайный** (`Randomize On Start = true`), игрок не знает его заранее — нужен объект в сцене, показывающий код.

1. Создай GameObject в сцене (например, лист бумаги на столе)
2. Добавь дочерний **Canvas** в режиме **World Space**, настрой размер
3. Внутри Canvas добавь `TextMeshProUGUI` — это будет поле для кода
4. Добавь компонент `CodeHintDisplay` на родительский GameObject
5. Назначь поля:


| Поле          | Что назначить                                           |
| ------------- | ------------------------------------------------------- |
| **Code Lock** | Компонент `CodeLock` замка, код которого нужно показать |
| **Code Text** | Компонент `TextMeshProUGUI` внутри Canvas               |


При старте игры `CodeHintDisplay` автоматически прочитает текущий код и запишет его в текстовое поле.

> В редакторе (без Play Mode) текст отображается как плейсхолдер (`"????"`). Реальный код появляется только при запуске игры.

## Управление при вводе кода


| Кнопка                        | Действие                |
| ----------------------------- | ----------------------- |
| `0–9` (клавиатура или нумпад) | Ввести цифру            |
| `Backspace`                   | Удалить последнюю цифру |
| `Enter`                       | Подтвердить код         |
| `Escape`                      | Закрыть панель          |


Код также подтверждается автоматически после ввода последней цифры.

## Тексты и цвета

Тексты "Доступ открыт" / "Неверный код" и цвета (зелёный/красный) настраиваются в `GameConfig`:

- **Code Lock Success Text**
- **Code Lock Wrong Text**
- **Success Color** / **Error Color**

Открой ассет `GameConfig` в Project и измени там — изменение применится ко всем замкам в игре.
