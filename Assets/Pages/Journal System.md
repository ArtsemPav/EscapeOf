Журнал — доска с зажимом: слева колонка кнопок категорий документов, справа стопка 3D-страниц, собираемая из существующих префабов документов и рендеримая отдельной камерой в `RawImage`. Листание — кликом по кнопкам-стрелкам по краям стопки или с клавиатуры. Записи активируются при **первом прочтении** документа в мире (`DocumentInteraction` → `DocumentData`) — сами записки при этом не исчезают.

## Компоненты

| Скрипт                                              | Роль                                                                                                        |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Assets/Scripts/Journal/JournalSystem.cs`           | Singleton: фиксированные категории, множество разблокированных документов, `ISaveable` (SaveId `journal`)   |
| `Assets/Scripts/Journal/UI/JournalUI.cs`            | Контроллер доски: категории, стопка страниц, камера, стрелки, клавиатура                                     |
| `Assets/Scripts/Journal/UI/JournalEntryButton.cs`   | Кнопка категории: `Setup(string label, Action onClick)` + подсветка выбранной                                |
| `Assets/Scripts/Journal/UI/JournalCategoryButton.cs`| Подкласс `Button`: сохраняет цвет выделения при наведении/фокусе (`SetForcedSelected`)                        |

**Регистрация записи:** единственная точка — хук `JournalSystem.Instance?.AddEntry(_documentData)` в `DocumentInteraction.Interact()`. `AddEntry` идемпотентен — повторные чтения безопасны. Прочитанные документы разблокируют свою категорию в журнале.

## Категории (JournalSystem)

Категории фиксированные и задаются в инспекторе `JournalSystem` — список `Categories`: имя + список `DocumentData` (порядок документов = порядок страниц в стопке). Все `DocumentData` лежат в `Assets/Data/Notes`. Кнопка категории показывается, только если в ней есть хотя бы один разблокированный документ.

## Листание (JournalUI)

Листание **мгновенное**, без анимации: `FlipRight()`/`FlipLeft()` вызывают `ShowPage(_currentPage ± 1)`. Страница появляется сразу в целевой позе (текущая приподнята на `Page Stack Offset`, прочитанные — веером слева).

Состояния страницы в стопке:

| Роль             | Поза                                        |
| ---------------- | ------------------------------------------- |
| прочитанные (веер)| сдвиг влево на `_pileShift` ширин листа + fan-поворот 2°/страницу (кап 20°) |
| current          | базовая поза + `_pageStackOffset` вверх      |
| next             | базовая поза, под current                    |

Клавиатура: `←`/`A` — назад, `→`/`D`/`Space` — вперёд, `Escape` — закрыть. J-логика обрабатывается `InputManager.OnJournalPerformed` (не меняется).

## Кнопки-стрелки

`LeftClickZone`/`RightClickZone` — `Image` со спрайтом рун (`T_Runes.png`), полноценные кнопки:

- `Button` с `Transition.ColorTint`: наведение — тёплая подсветка `(1, 0.92, 0.7)`, нажатие — затемнение `(0.7, 0.7, 0.7)`, `fadeDuration = 0.1`. `targetGraphic` привязывается явно.
- Стрелка **скрывается** (`interactable = false` + `enabled = false`), если страницы в эту сторону нет (`UpdateEdgeZoneAvailability` вызывается в конце `ShowPage`).

## Кадрирование и нормализация страниц

Все страницы нормализуются в фиксированный кадр — визуальный размер и расположение одинаковы для любых документов:

- `DocumentData.previewRotation` (`GetPreviewRotation`) — стартовый поворот инстанса; `previewScale` — стартовый масштаб.
- `FitInstanceIntoFixedFrame` — масштабирует инстанс по bounds всех рендереров так, чтобы страница заполнила ~90% кадра `_fixedBoundsSize`.
- `ComputeFrame`/`FrameCamera` — ортографическая камера кадрирует стопку: прижата к правой границе (`_stackRightShift`), прочитанные уходят влево (`_pileShift`).

## Поля JournalUI (инспектор на `/JournalUIRoot`)

| Поле                   | По умолчанию           | Описание                                                         |
| ---------------------- | ---------------------- | ---------------------------------------------------------------- |
| **Page Stack Offset**  | `0.1`                  | Подъём текущей страницы над стопкой                              |
| **Stack Right Shift**  | `0.16`                 | Прижатие стопки к правой границе кадра (в ширинах листа)         |
| **Pile Shift**         | `1`                    | Выдвижение стопки прочитанных влево (в ширинах листа)            |
| **Framing Multiplier** | `2.2`                  | Множитель зума камеры (больше = страницы меньше)                 |
| **Fixed Bounds Size**  | `(0.44, 0.025, 0.31)`  | Эталонный размер страницы для кадра, нормализации и всех сдвигов |
| **Fixed Bounds Center Offset** | `(0, 0.006, 0)` | Смещение центра bounds                                           |
| **Pages Container Name** | `Pages`              | Имя контейнера страниц в префабе документа                       |

## Сохранение

`JournalSystem` реализует `ISaveable` (SaveId `journal`): в сейв пишется список имён разблокированных `DocumentData`, восстановление через `Resources.FindObjectsOfTypeAll`. Категории в сейв не пишутся.

## Известные ограничения

- Категория без разблокированных документов: кнопка скрыта; если категория пуста совсем — стрелки не обновятся (ранний `return` в `ShowPage`).
- Разные меши бумаги (`Paper` у базового префаба и `HalfPaperCut` у `PRF_PaperNoteFtueBase`) дают немного разный аспект страниц после нормализации — при необходимости унифицировать меш в FTUE-базе.
