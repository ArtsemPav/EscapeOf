# Редактор локализации (офлайн, без Unity)

Один файл `LocalizationEditor.html` + папка `fonts/` — ни установки, ни интернета, ни Unity не требуется.

## Для переводчика

1. Откройте `LocalizationEditor.html` двойным кликом (любой современный браузер).
   Папку `fonts` держите рядом с HTML — в ней лежат шрифты игры для предпросмотра.
2. Перетащите в окно файлы `Ru.asset` и `En.asset` (или «Загрузить файлы…»).
3. Ячейка показывает **предпросмотр вёрстки**: жирный, курсив, цвета, размер, шрифт — как в игре.
   Кликните по ячейке, чтобы править текст с тегами и панелью форматирования:
   - **Ж / К / Ч / З** — обернуть выделение (или весь текст) в `<b>`, `<i>`, `<u>`, `<s>`;
   - палитра — цвет текста `<color=#…>`, кнопка «Фон» — `<mark=#…>`;
   - «Шрифт…» — обернуть текст тегом шрифта игры `<font="Имя шрифта">` (шрифты из проекта);
   - «✕ теги» — снять все теги с ячейки.
   Клик вне ячейки возвращает предпросмотр. Теги и переводы строк сохраняются в файл как есть.
4. Нажмите «Сохранить Ru.asset» / «Сохранить En.asset» — браузер скачает обновлённые файлы.
5. Отправьте файлы разработчику.

## Для разработчика

Положите скачанные файлы обратно в `Assets/Data/Localization/Resources/Localization/`
с заменой. Unity импортирует их как обычные `LocalizedTextTable` — правки сразу видны в игре.

Не меняйте ключи в файлах вручную вне редактора: ключи используются в коде
(см. `Assets/Scripts/Core/LocalizationKeys.cs`), переименование ключа ломает текст в игре.

## Что редактор не делает

- Не правит таблицы спрайтов (`RuSprites.asset` / `EnSprites.asset`) — там ссылки на ассеты Unity.
- Не правит отдельные текстовые документы блокнота (`Text/*.txt`, `*_En.txt`).
- Выбор шрифта вставляет TMP-тег `<font="…">`; превью показывает реальные TTF из `fonts/`,
  но применять шрифт к тексту в игре нужно средствами TMP (тег читается автоматически).
