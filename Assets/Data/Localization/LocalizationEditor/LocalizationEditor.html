Редактор локализации

Файлы не загружены.
Перетащите сюда Ru.asset и En.asset
(или нажмите «Загрузить файлы…»). Файлы лежат в
Assets/Data/Localization/Resources/Localization/
Правьте текст в ячейках — правки сохраняются в файлы по кнопкам «Сохранить …» вверху. Ключи менять нельзя, они используются в игре. Ячейка по умолчанию показывает предпросмотр вёрстки (жирный, курсив, цвета, шрифты — как в игре); клик по ячейке открывает режим правки с тегами <b>, <i>, <color=…>, <font=…> и панелью форматирования. Теги и переводы строк нужно сохранять как есть. Ячейку с правкой видно по оранжевой подсветке до момента сохранения.
Как передать правки разработчику

1. Нажмите «Сохранить Ru.asset» / «Сохранить En.asset» — браузер скачает обновлённые файлы.
2. Отправьте файлы разработчику.
3. Разработчик заменит ими файлы в папке Assets/Data/Localization/Resources/Localization/ проекта — Unity подхватит правки автоматически.

Редактор работает офлайн, файлы никуда не отправляются.
